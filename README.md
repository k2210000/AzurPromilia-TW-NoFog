# 藍色星原：旅謠｜台服反虛化工具

適用於《藍色星原：旅謠》台灣伺服器的非官方反虛化研究工具。提供完整反虛化資源、相容性檢查及原始檔案備份與還原功能，保留遊戲原有的繁體中文。

> [!WARNING]
> 本專案為非官方候選測試版，尚未完成 Windows 安裝、遊戲登入及反作弊相容性測試。離線校驗通過不代表遊戲實際可用或官方允許修改，也不能保證帳號安全。請先確認官方使用條款及測試授權；不建議於未經授權的正式連線環境使用。

## 功能

- 角色、NPC、騎乘及已驗證的單一建築元件反虛化資源修改。
- 保留台服原生繁體中文，無須安裝簡體漢化。
- Windows 批次檔操作，無須安裝 Python。
- 支援手動輸入遊戲根目錄或拖曳資料夾。
- 安裝前檢查資源版本、檔案大小及 SHA-256。
- 自動備份原始資源、驗證備份及還原。
- 安裝失敗時嘗試回滾，遇到未知資源或不相容版本時停止。
- 不修改遊戲執行檔、啟動器或 Manifest。

目前僅提供全功能模式，尚不提供各項功能的獨立開關。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `01-Check.bat` | 唯讀相容性檢查，不修改遊戲資源。 |
| `02-Apply.bat` | 安裝候選資源，先驗證並備份。 |
| `03-Restore.bat` | 使用已驗證的備份還原原始資源。 |
| `Candidate.ps1` | PowerShell 核心程式。 |
| `plan.json` | 資源版本、路徑、大小與雜湊驗證資料。 |
| `payload/` | 四個候選替換資源（僅於取得合法使用及散布權限時提供）。 |

公開原始碼不一定包含 `payload/`；沒有完整且相符的資源時，檢查及安裝功能會停止。請勿從來源不明的網站下載替換資源。

## 使用方式

### 1. 準備

完整解壓縮至獨立資料夾，保留原有目錄結構。先關閉遊戲及啟動器（含背景程序），並確認你有權在指定環境測試。

### 2. 相容性檢查

雙擊 `01-Check.bat`，按照提示輸入包含 `AzurPromilia_Data` 的遊戲根目錄，例如：

```text
D:\Games\AzurPromilia_TC_game
```

不要輸入 `AzurPromilia_Data` 本身，也不要輸入遊戲 EXE 的完整路徑。亦可將遊戲根目錄資料夾直接拖曳至 BAT 上。輸入空白後按 Enter 可取消。

成功時會顯示：

```text
Static compatibility checks passed. Runtime not verified.
Exit code: 0
```

請注意，取消操作也可能返回 `Exit code: 0`，因此應確認實際顯示的訊息。`Original` 表示符合原始雜湊，`Modified` 表示符合本版候選資源雜湊，`Unknown` 則會停止操作。靜態檢查通過不代表遊戲實際載入已驗證。

### 3. 安裝候選資源

僅在官方允許且有權進行修改的測試環境使用。確認檢查通過後，雙擊 `02-Apply.bat`，輸入相同的遊戲根目錄。閱讀提示後，輸入大寫 `APPLY` 確認。程式會確認四個目標檔案皆為原始版本，驗證備份後才進行替換。

### 4. 還原

關閉遊戲及啟動器，雙擊 `03-Restore.bat`，輸入原本的遊戲根目錄，並輸入大寫 `RESTORE`。還原後會保留備份。

若遊戲已更新、備份不完整、路徑或雜湊不符，請停止操作並使用官方遊戲修復功能，不要手動強制覆蓋舊版資源。

## 備份位置

安裝前會備份四個原始資源，並驗證其 SHA-256。備份位於遊戲根目錄下：

```text
AzurPromilia_Data/
└── .tw-deblur-3221746-backup/
    ├── d3svzxgozq953wetzjanua.r
    ├── s6ppge3l6q1q9htrof7qcq.r
    ├── tsn5bfvm7hx6csi1reyrya.r
    ├── wf4ksai7xalfafyxycu1g.r
    └── state.json
```

請勿刪除或修改備份。備份僅包含四個目標資源，不是完整遊戲備份。移除下載的工具資料夾不會自動移除遊戲內的備份。建議遊戲更新前先還原；備份不能避免帳號風險。

## 常見問題

### PowerShell 顯示「未經數位簽署」或 `UnauthorizedAccess`

從網路下載的 ZIP 或解壓後的 PowerShell 指令碼可能保留 Windows 的下載來源標記。工具 BAT 使用單次行程的 `RemoteSigned` 執行原則，因此帶有網路來源標記的未簽署腳本可能無法執行。

先確認下載來源可信，並使用記事本檢閱 `Candidate.ps1`。不要對來源不明的指令碼解除封鎖。

**方法一：透過檔案內容解除封鎖**

1. 右鍵點選 `Candidate.ps1` → **內容**。
2. 在「一般」頁籤下方，若有「解除封鎖」選項，勾選後按「套用」及「確定」。
3. 重新執行 `01-Check.bat`。

也可在解壓縮之前對可信的 ZIP 檔案進行相同操作，再重新解壓縮。若沒有「解除封鎖」選項，可使用下方方法檢查。

**方法二：使用 PowerShell**

開啟 PowerShell，將下方範例中的路徑替換為自己的實際檔案位置：

```powershell
Unblock-File -LiteralPath "D:\Downloads\AzurPromilia_TW_Full_v0.8.1\Candidate.ps1"
```

指令執行後沒有輸出通常是正常現象。接著重新雙擊 `01-Check.bat`。

若仍然失敗，請查看執行原則：

```powershell
Get-ExecutionPolicy -List
```

如果是 `AllSigned` 或組織的群組原則限制，請遵循系統管理者的要求。不要永久降低系統執行原則，不需要關閉防毒軟體，也不建議使用 `Bypass` 作為一般解決方式。

### 找不到遊戲或路徑無效

請選擇包含 `AzurPromilia_Data` 的資料夾。工具沒有固定磁碟代號，亦不需要將遊戲移到特定位置。符號連結、接合點等重新解析點可能被拒絕。

### `Manifest mismatch`、`Newer manifest detected`、`Unknown file`

代表遊戲資源版本或實際內容不符合本版基準。請停止安裝或還原，不要編輯 `plan.json` 來略過驗證。

### 安裝失敗、遊戲異常或無法登入

停止使用修改資源。若版本未變且備份完整，可使用還原功能；否則請使用官方修復功能。不要重複嘗試登入以驗證修改是否可用。
