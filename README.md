# 藍色星原：旅謠｜台服反虛化工具

適用於《藍色星原：旅謠》台灣伺服器的非官方反虛化研究工具。提供完整反虛化資源、相容性檢查及原始檔案備份與還原功能，保留遊戲原有的繁體中文。

## 功能

- 角色、NPC、騎乘及已驗證的單一建築元件反虛化資源修改。
- 保留台服原生繁體中文，無須安裝簡體漢化。
- Windows 批次檔操作，無須安裝 Python。
- 支援手動輸入遊戲根目錄或拖曳資料夾。
- 安裝前檢查資源版本、檔案大小及 SHA-256。
- 自動備份原始資源、驗證備份及還原。
- 安裝失敗時嘗試回滾，遇到未知資源或不相容版本時停止。
- 不修改遊戲執行檔、啟動器或 Manifest。

目前僅提供全功能模式，尚不提供各項功能的獨立開關。

## 支援版本

| 項目 | 版本 |
| --- | --- |
| 適用伺服器 | 台服 |
| 線上更新資源 | `3221746` |
| 遊戲內建資源 | `3060618` |
| 執行環境 | Windows、Windows PowerShell |

資源版本並非遊戲顯示的版本號。即使版本號相同，也必須通過檔案雜湊檢查。遊戲更新後不保證相容，請勿強制套用舊版資源。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `01-備份.bat` | 手動備份目前的四個遊戲資源，不修改原始檔案。 |
| `02-安裝.bat` | 自動備份、驗證並安裝反虛化資源。 |
| `03-還原.bat` | 使用最近一次安裝前的備份還原遊戲資源。 |
| `Tool.ps1` | PowerShell 核心程式，負責備份、安裝、還原及檔案完整性驗證。 |
| `使用說明.txt` | 工具使用方式及注意事項。 |
| `payload/` | 四個反虛化替換資源（僅於取得合法使用及散布權限時提供）。 |

## 使用方式

### 1. 準備

完整解壓縮至獨立資料夾，保留原有目錄結構，並確認 `payload/` 內包含完整的四個替換資源。

先完全關閉遊戲及啟動器（含背景程序），並確認你有權在指定環境使用本工具。

執行批次檔後，依照提示輸入包含 `AzurPromilia_Data` 的遊戲根目錄，例如：

```text
D:\Games\AzurPromilia_TC_game
```

亦可將遊戲根目錄資料夾直接拖曳至批次檔上。工具會自動辨識常見的台服遊戲目錄結構。

### 2. 備份（選用）

雙擊 `01-備份.bat`，輸入遊戲根目錄，並依照提示輸入「確認」。

工具會備份目前的四個遊戲資源，並透過 SHA-256 驗證備份完整性，不會替換任何遊戲資源。

由於安裝功能已包含自動備份，因此不需要在每次安裝前手動執行此步驟。

### 3. 安裝反虛化

1. 雙擊 `02-安裝.bat`。
2. 輸入遊戲根目錄，或將遊戲資料夾拖曳至批次檔上。
3. 閱讀安裝提示及相容性警告。
4. 輸入「確認」開始安裝。
5. 等待備份、資源替換及完整性驗證完成。

工具會在安裝前自動備份四個遊戲資源，確認備份完整後才進行替換。若安裝過程發生錯誤，將嘗試回復已處理的檔案。

v1.0.1 不再強制驗證 Manifest 資源版本，因此不會單純因資源版本號不同或指定 Manifest 不存在而中止安裝。

但遊戲更新後仍可能存在相容性問題，安裝成功僅代表檔案複製及完整性驗證通過，不代表遊戲實際運行相容。

若已安裝其他版本的反虛化補丁，請先還原或使用官方遊戲修復功能，再安裝本版本。

### 4. 還原

1. 完全關閉遊戲及啟動器。
2. 雙擊 `03-還原.bat`。
3. 輸入原本的遊戲根目錄。
4. 輸入「確認」開始還原。
5. 等待還原及完整性驗證完成。

工具會自動尋找最近一次安裝前的備份，並驗證目前的遊戲資源是否與該次安裝後的紀錄一致。

還原完成後仍會保留備份，不會自動刪除。

若遊戲已更新、備份不完整，或目前資源與安裝紀錄不符，請使用官方遊戲修復功能，不要強制覆蓋舊版備份。

## 備份位置

手動備份、安裝前備份及還原前備份均會儲存在遊戲資料目錄下：

```text
AzurPromilia_Data/
└── .tw-deblur-simple-backup/
    └── 日期_時間_識別碼_install/
        ├── d3svzxgozq953wetzjanua.r
        ├── s6ppge3l6q1q9htrof7qcq.r
        ├── tsn5bfvm7hx6csi1reyrya.r
        ├── wf4ksai7xalfafyxycu1g.r
        └── state.json
```

每次備份均會建立獨立資料夾，不會覆蓋先前的備份。

| 備份目錄後綴 | 用途 |
| --- | --- |
| `_manual` | 使用手動備份功能建立的備份。 |
| `_install` | 安裝反虛化前建立的備份。 |
| `_pre_restore` | 還原前建立的備份，用於還原失敗時嘗試回復。 |

還原工具預設使用最近一次 `_install` 備份，不會自動選用手動備份。

請勿任意刪除或修改備份內容及 `state.json`。備份僅包含四個目標資源，並非完整遊戲備份。

移除下載的工具資料夾不會自動移除遊戲內的備份。建議在遊戲更新前先還原原始資源；備份不能避免帳號風險。

## 常見問題

### PowerShell 顯示「未經數位簽署」或 `UnauthorizedAccess`

從網路下載的 ZIP 或解壓後的 PowerShell 指令碼可能保留 Windows 的下載來源標記。工具 BAT 使用單次行程的 `RemoteSigned` 執行原則，因此帶有網路來源標記的未簽署腳本可能無法執行。

先確認下載來源可信，並使用記事本檢閱 `Tool.ps1`。不要對來源不明的指令碼解除封鎖。

**方法一：透過檔案內容解除封鎖**

1. 右鍵點選 `Tool.ps1` → **內容**。
2. 在「一般」頁籤下方，若有「解除封鎖」選項，勾選後按「套用」及「確定」。
3. 重新執行所需的批次檔。

也可在解壓縮之前對可信的 ZIP 檔案進行相同操作，再重新解壓縮。

**方法二：使用 PowerShell**

開啟 PowerShell，將下方範例中的路徑替換為自己的實際檔案位置：

```powershell
Unblock-File -LiteralPath "D:\Downloads\AzurPromilia_TW_v1.0.1\Tool.ps1"
```

指令執行後沒有輸出通常是正常現象。接著重新執行批次檔。

若仍然失敗，請查看執行原則：

```powershell
Get-ExecutionPolicy -List
```

如果是 `AllSigned` 或組織的群組原則限制，請遵循系統管理者的要求。不要永久降低系統執行原則，不需要關閉防毒軟體，也不建議使用 `Bypass` 作為一般解決方式。

### 找不到遊戲或路徑無效

請選擇包含 `AzurPromilia_Data` 的遊戲根目錄。

工具沒有固定磁碟代號，亦不需要將遊戲移到特定位置。不支援透過符號連結、接合點等重新解析點存取遊戲資源。

### 找不到替換資源或資源重複

請確認已完整解壓縮工具，且 `payload/` 內包含以下四個檔案：

```text
d3svzxgozq953wetzjanua.r
s6ppge3l6q1q9htrof7qcq.r
tsn5bfvm7hx6csi1reyrya.r
wf4ksai7xalfafyxycu1g.r
```

每個檔名只能存在一份，可以保留原有子資料夾結構。

### 找不到 Manifest 或遊戲資源版本不同

自 v1.0.1 起，工具不再強制驗證 Manifest，也不限制指定的遊戲資源版本。

只要四個目標資源存在，並通過工具的備份及複製完整性檢查，即可在確認風險後嘗試安裝。

但這不代表所有遊戲版本均相容。若官方修改了目標資源內容、檔名、封包結構或相關依賴資源，仍可能造成反虛化失效或遊戲異常。

### 偵測到檔案已與替換資源相同

代表至少一個遊戲資源已與目前的反虛化替換資源相同，可能是先前已經安裝過補丁。

為避免將修改後的資源誤認為原始資源並建立錯誤備份，工具會中止操作。

請先使用還原工具或官方遊戲修復功能，再重新安裝。

### 目前遊戲資源與安裝後紀錄不符

可能是遊戲已經更新、執行過官方修復，或資源已被其他工具修改。

為避免舊版備份覆蓋新版遊戲資源，還原工具會中止操作。此時請優先使用官方遊戲修復功能。

### 安裝失敗、遊戲異常或無法登入

停止使用修改資源。若版本未變且備份完整，可使用還原功能；否則請使用官方修復功能。不要重複嘗試登入以驗證修改是否可用。
